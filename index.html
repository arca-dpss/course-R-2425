Goals

  • Learn all the main elements that make up the R language
  • Learn the general logic of programming, useful with any language
  • Improve the way we approach problems and make everyday work more efficient

How the lessons are organized

  • Theoretical and logical understanding of the topics
  • Understanding code output, error messages and special cases
  • Hands-on practice writing code and solving exercises

Exam

  • Format: The exam will consist of several exercises.
  • Topics: The exercises will cover the topics presented during the course.
  • Allowed material: You may use the material provided during the lessons. Other online material (or ChatGPT) is not allowed during the exam.
  • Duration: 1 hour
  • Mode: in class
