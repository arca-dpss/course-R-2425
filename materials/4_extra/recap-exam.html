Operations and missing values

Operations work element by element, summary functions return one value

[1] NA

[1] 17

[1] FALSE FALSE  TRUE FALSE FALSE

[1] 1

Modifying with indexing

Indexing + <- modifies only the selected elements:

[1] 21 21 30 22 21

Adding a new level

To use a new value, first add it to the levels

group
[1] placebo  caffeine nicotine placebo  caffeine
Levels: caffeine nicotine placebo
levels(group) <- c(levels(group), "water")
group[1] <- "water"
group
[1] water    caffeine nicotine placebo  caffeine
Levels: caffeine nicotine placebo water

Reorder vs rename

group <- factor(x = c("placebo", "caffeine", "nicotine",
                  "placebo", "caffeine"))
# REORDER: placebo first (reference category), same data
group_ord <- factor( x = c("placebo", "caffeine", "nicotine",
                  "placebo", "caffeine"),
  levels = c("placebo", "caffeine", "nicotine"))
levels(group_ord)
[1] "placebo"  "caffeine" "nicotine"
# RENAME: by position, check levels() first!
levels(group_ord) <- c("PLA", "CAF", "NIC")
group_ord
[1] PLA CAF NIC PLA CAF
Levels: PLA CAF NIC

Reorder and rename in one step

factor() with both arguments:

  • levels: the existing values, in the order we want
  • labels: their new names, in the same order
group_new <- factor(x = c("placebo", "caffeine", "nicotine",
                  "placebo", "caffeine"),
  levels = c("placebo", "caffeine", "nicotine"),
  labels = c("PLA", "CAF", "NIC"))
group_new
[1] PLA CAF NIC PLA CAF
Levels: PLA CAF NIC
levels(group_new)
[1] "PLA" "CAF" "NIC"

Before the exam

Remember

  • <- creates objects, == compares
  • text always goes in quotes: "hello", "5"
  • with missing values: mean(x, na.rm = TRUE)
  • vectors and matrices hold one type of data
  • before renaming levels, look at levels(x); to reorder and rename use factor(x, levels, labels)
  • to use a new value in a factor, add its level first
  • lists: [[ ]] or $ to get an element
  • dataframes: df[rows, columns], e.g. df[df$score > 20, ]
  • rbind(): same column names; merge(): a common key

Function summary

structure dimensions types create index
vector 1 one c(), seq(), rep() x[i]
factor 1 categories factor() x[i], levels()
list 1 (nested) any list() x[i], x[[i]], x$name
matrix 2 one matrix(), cbind() x[row, col]
dataframe 2 one per column data.frame() x$col, x[row, col]
