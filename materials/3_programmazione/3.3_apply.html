3.3_apply

*apply family

Imagine you have a list of vectors and you want to apply the same function(s) to each element of the list:

  • I apply the function manually, selecting the elements

  • a for loop that iterates over the elements of the list and applies the function(s)

    …

my_list=list(
    var1=rnorm(n = 100, mean = 0, sd = 1),
    var2=runif(n = 100, min = 0, max = 1),
    var3=rnorm(n = 100, mean = 0, sd = 1),
    var4=rnorm(n = 100, mean = 0, sd = 1)
)

*apply family

Let’s compute mean, median and std

# initialize the vectors with arbitrary numbers,
# but as many as we need
means = 1:length(my_list)
medians = 1:length(my_list)
stds = 1:length(my_list)

# Loop
for(i in 1:length(my_list)){

  means[i] = mean(my_list[[i]])
  medians[i] = median(my_list[[i]])
  stds[i] = sd(my_list[[i]])
}

Result

*apply family

Everything works! but:

  • writing the for loop is laborious, with indices both for the list and for the vector we are filling

  • we need to pre-allocate variables (for speed reasons)

  • 8 lines of code (for this simple example)

*apply family

R has a family of apply functions such as lapply, sapply, etc. that let us get the same result in a more concise, fast and simple way:

means = sapply(my_list, mean)
medians = sapply(my_list, median)
stds = sapply(my_list, sd)

*apply family - implicit vs. explicit

So, just as the for loop written as i in vec assigns to i one element of the vec object at a time, internally the *apply functions take the first element of the input object (list) and directly apply the function we have chosen.

implicit sapply

vec = 1:5
res = sapply(vec, print)
[1] 1
[1] 2
[1] 3
[1] 4
[1] 5

explicit sapply

vec = 1:5
res = sapply(vec, function(i) print(i))
[1] 1
[1] 2
[1] 3
[1] 4
[1] 5

*apply family - anonymous function

An anonymous function is a function that is not saved in an object but written to be executed directly, inside other functions that allow it:

All the types of *apply

  • lapply(): the basic function

  • sapply(): simplified-apply

  • tapply(): rarely used, useful with factors

  • apply(): useful for dataframes/matrices

  • mapply(): multivariate version, uses several lists at the same time

  • vapply(): used inside functions and packages

lapply

lapply stands for list-apply and always returns a list, applying the function to each element of the input list:

res = lapply(my_list, mean)
res
$vec1
[1] 0.3913664

$vec2
[1] 0.6047078

$vec3
[1] 0.3667684
class(res)
[1] "list"

sapply

sapply stands for simplified-apply and (tries to) return a simpler version of a list, applying the function to each element of the input list:

res = sapply(my_list, mean)
res
     vec1      vec2      vec3 
0.3913664 0.6047078 0.3667684 
class(res)
[1] "numeric"

apply works specifically on dataframes or matrices, applying a function to the rows or the columns:

tapply

tapply lets us apply a function to a vector, splitting the vector according to a categorical variable:

vec = rnorm(75)

index = rep(c("a", "b", "c"), each = 25)

tapply(vec, INDEX = index, mean)
          a           b           c 
-0.21304399  0.02248281  0.05038133

Here INDEX is a character vector or a factor.

vapply

vapply is a more robust version of the previous ones from a programming point of view. In practice it lets (and requires) us to specify in advance the type of data we expect as a result:

vapply(my_list, FUN = mean, FUN.VALUE = numeric(length = 1))
     vec1      vec2      vec3 
0.3913664 0.6047078 0.3667684

FUN.VALUE = numeric(length = 1): indicates that each result is a single numeric value.

mapply

mapply lets us handle several lists at the same time for more complex scenarios. For example, we want to use the rnorm() function to generate 4 samples combining different means and standard deviations:

mus = list(10, 20, 30, 40)
stds = list(1, 2, 3, 4)

mapply(function(x,y) rnorm(n = 5, mean = x, sd = y),
       mus, stds, SIMPLIFY = FALSE)
[[1]]
[1] 10.625957 10.889984 10.024787  9.246613  9.391001

[[2]]
[1] 19.22194 15.83161 20.22224 18.65874 17.34550

[[3]]
[1] 28.48536 28.33813 29.93324 32.68209 29.18278

[[4]]
[1] 42.25903 40.19806 47.91491 35.46042 40.21208

IMPORTANT: all the lists included must have the same length!

mapply

mapply(function(x,y) rnorm(n = 5, mean = x, sd = y), mus, stds, SIMPLIFY = FALSE)

  • function(...): an anonymous function, as we saw before, which can have n elements

  • rnorm(n = 5, mean = x, sd = y): the actual anonymous function, where we have the placeholders x and y

  • mus, stds: the lists corresponding, in order, to the placeholders, so x = mus and y = stds

  • SIMPLIFY = FALSE: simply says to return a list and not to try (like sapply) to simplify the result

mapply as a for

The same result (in a more verbose way) can be obtained with a for loop, using the iterator i several times:

mus = list(10, 20, 30)
stds = list(1,2,3)
res = vector(mode = "list", length = length(mus)) # empty list

for(i in 1:length(mus)){
  res[[i]] = rnorm(n = 6, mean = mus[[i]], sd = stds[[i]])
}

replicate

This function lets us repeat an operation n times, without using an iterator or a placeholder.

replicate(n, expr)

  • n is the number of repetitions

  • expr is the portion of code to repeat

replicate

We sample 1000 times from a normal distribution and compute the mean, AKA the sampling distribution of the mean

nrep=1000

nsample=30

mu=100

sd=30

means=
  replicate(
    n = nrep,
    expr = {mean(
      rnorm(nsample, mu, sd))}
    )
