Dataframe

The dataframe is the most “complex”, useful and powerful structure in R. Intuitively it is an excel sheet, while from R’s point of view it is a type of list with some properties/restrictions

  • each element of the list is a vector with an associated name (aka a column)
  • each list/column must have the same number of elements
  • as a consequence, each row has the same number of elements (rectangular structure)

Creation

Most of the time you will import dataframes rather than create them, but it is important to first understand how they work and how to create/manipulate them. They are created with the data.frame command

# Create a dataframe with 3 columns
my_df = data.frame( col1 = 1:4, col2 = letters[1:4],
                    col3 = rnorm(n = 4, mean = 0, sd = 1))
my_df
  col1 col2       col3
1    1    a -1.2164427
2    2    b  0.9578252
3    3    c  1.2170114
4    4    d  0.5070257

Attributes

The dataframe has both the attributes of a list, i.e. the names, and the attributes of a matrix, i.e. the dimensions (rows and columns)

typeof(my_df)
[1] "list"
attributes(my_df)
$names
[1] "col1" "col2" "col3"

$class
[1] "data.frame"

$row.names
[1] 1 2 3 4
dim(my_df)
[1] 4 3

As with the other structures we have seen, we can use the functions names() , dim(), nrow(), ncol()… to get information about the properties of the dataframe. The most useful function is str(), since it gives us a quick overview of the structure of the dataframe: dimensions, variable types,…

str(iris) # iris is a dataset available by default in R (?iris)

Indexing

We can use either square brackets []:

my_df[1]  # extract a 4x1 data.frame
  col1
1    1
2    2
3    3
4    4
my_df[[1]] # extract the first column of the data.frame
[1] 1 2 3 4
my_df[1,1] # extract the first element of the first column of the data.frame
[1] 1

or the dollar sign $

my_df$col1 # extract the first column of the data.frame
[1] 1 2 3 4
my_df$col1[1] # extract the first element of the first column of the data.frame
[1] 1

Indexing - Relational operators

One of the most common operations you will deal with is extracting/evaluating a subset of the values in your dataset:

my_df
  col1 col2       col3
1    1    a -1.2164427
2    2    b  0.9578252
3    3    c  1.2170114
4    4    d  0.5070257
# keep only the rows where the values of column1 are greater than 2
my_df[my_df$col1 > 2, ]
  col1 col2      col3
3    3    c 1.2170114
4    4    d 0.5070257
my_df[my_df[1] > 2, ]
  col1 col2      col3
3    3    c 1.2170114
4    4    d 0.5070257

Examples

Indexing

There are also alternative, more compact ways of indexing. For example, using the subset() function:

subset(iris, subset = Species == "setosa" & Petal.Length > 1.7)
   Sepal.Length Sepal.Width Petal.Length Petal.Width Species
25          4.8         3.4          1.9         0.2  setosa
45          5.1         3.8          1.9         0.4  setosa

equivalent to:

iris[iris$Species == "setosa" & iris$Petal.Length > 1.7,]
   Sepal.Length Sepal.Width Petal.Length Petal.Width Species
25          4.8         3.4          1.9         0.2  setosa
45          5.1         3.8          1.9         0.4  setosa

We can also select columns rather than rows with the select argument:

subset(iris, select = c(Sepal.Length, Species))
# show the first rows with the head command
head(subset(iris, select = c(Sepal.Length, Species)), n = 3)
  Sepal.Length Species
1          5.1  setosa
2          4.9  setosa
3          4.7  setosa

We can also combine the two:

subset(iris, subset = Species == "setosa" & Sepal.Length > 4, select = c(Sepal.Length, Species))
head(subset(iris, subset = Species == "setosa" & Sepal.Length > 4, select = c(Sepal.Length, Species)), n = 3)
  Sepal.Length Species
1          5.1  setosa
2          4.9  setosa
3          4.7  setosa

… equivalent to:

head(iris[iris$Species == "setosa" & iris$Sepal.Length > 4, c("Sepal.Length","Species")],n = 3)
  Sepal.Length Species
1          5.1  setosa
2          4.9  setosa
3          4.7  setosa

The same concepts we have seen for vectors apply, so you can both create and modify variables.

my_df = data.frame(num = 1:4, let = letters[1:4])

# Modify the num variable by adding 1

# Create a third variable made of the num and let variables
my_df$both = paste(my_df$num,my_df$let, sep = "_") # ?paste

Combining Dataframes

Since they are similar to matrices, dataframes can be combined with the rbind() function:

# first dataframe
str(my_df)
'data.frame':   4 obs. of  3 variables:
 $ num : num  2 3 4 5
 $ let : chr  "a" "b" "c" "d"
 $ both: chr  "2_a" "3_b" "4_c" "5_d"
# create a second dataframe
my_df2 = data.frame(num = 4:7, lett = letters[1:4],
                    both = paste(4:7,letters[1:4], sep = "_"))

                                     each = 200, times = 2)),

Contingency tables

We can use the table() function both to compute frequencies and to compute contingency tables, for example to see how many trials we have for each subject.

# keep only rts between .250 and 1.5 seconds
# i.e. the rows that meet this condition
df_rt_clean = df_rt[df_rt$rt > .25 & df_rt$rt < 1.5, ]

# how many trials for each subject
table(df_rt$subj)

alice   bob 
  400   400 
table(df_rt_clean$subj)

alice   bob 
  369   396 
# how many trials for each subject x condition
table(df_rt_clean$subj, df_rt_clean$cond)
       
        easy hard
  alice  186  183
  bob    200  196

Exporting and importing data

In R we can import data in many different formats; most commonly you will import .csv or .xlsx data.

Here, for example, I export the dataframes in two different formats…

library(readr) # load the readr package
library(writexl) # load the writexl package

write.csv(df_rt, file = "DATA/df_rt.csv",row.names = FALSE)
write_xlsx(df_age, path = "DATA/df_age.xlsx")

Importing

library(readxl) # load the readxl package

df_rt_impo = read_csv("DATA/df_rt.csv") # uses the readr package

df_age_impo = read_xlsx("DATA/df_age.xlsx")

The examples I have shown concern data in formats external to R, but we can also save and import data in R formats.

Their main drawback is that they can be read (mainly) only within the R environment.

If we need to work with different software or languages, it is probably better to use a more generic format.
